# PROJECT_SNAPSHOT.md — PILOTE - Kit Site Web

## But
Carnet de bord réutilisable ("kit méthode") pour construire des sites web premium pour Atelier Klar, distillé du chantier réel 9MM/MerchOFF. Objectif explicite : ne jamais réapprendre deux fois la même chose — chaque nouveau site client démarre à partir de ce kit. Contient aussi désormais le volet prospection commerciale d'Atelier Klar (trouver des clients, pas juste construire des sites).

## Contenu/Stack
- 9 dossiers numérotés couvrant tout le cycle : `00-METHODE` (templates CLAUDE.md/docs), `01-MARQUE-STRATEGIE`, `02-CONTENU-IA` (règles IA + recettes ffmpeg), `03-DESIGN-ANIMATION`, `04-DEPLOIEMENT-PREVIEW` (Netlify), `05-HANDOFF` (livraison dev externe, zéro trace IA), `06-CONFORMITE` (RGPD/CNIL/WCAG), `07-PROSPECTION` (ICP v2, briefs, lots de prospects, outreach), `99-SOURCES`.
- `KlarSignature/` : vault Obsidian (Méthode, Décisions, Questions ouvertes, Projets) contenant notamment le "Protocole Klar" (recette canonique de site d'exception).
- Fichiers de pilotage : `README.md`, `CHECKLISTS.md`, `SKILLS.md`, `snapshot.md`, `historique.md`, `PROCHAINE-ETAPE.md`, deux audits datés (05 et 06 juillet).
- Stack technique visée pour les sites produits : HTML/CSS/JS animé (scroll), Netlify, ffmpeg pour vidéos, Higgsfield/Canva pour visuels IA.
